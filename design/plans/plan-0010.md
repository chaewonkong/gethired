## 레인 A: 백엔드 (`backend/`)
### A1 `feat(backend): demo mode module`
- `repository.py`: `_fixed_now: str | None`, `set_fixed_now(iso: str | None)`. `now_iso()`는 고정값이 있으면 그대로 반환. `api.py`·`jobs.py`·`profile.py`가 `from .repository import now_iso`로 함수를 가져가므로 함수 본문에서 분기해야 셋 다 먹는다
- `app/demo.py`
  - `FIXED_NOW = "2026-10-18T09:00:00+09:00"`, `COMPANIES`, 공고·판정 데이터는 위 표 그대로 (`RawPosting` 8건, `external_id`는 `demo-toss-1` 식)
  - `DemoScraper(Scraper, register=False)` 서브클래스 4개. `fetch()`는 client를 쓰지 않고 고정 리스트 반환
  - `PROFILE: Profile` 고정 (홍길동, 백엔드 5년, Go·Redis·Kubernetes·PostgreSQL, 도메인 매치메이킹)
  - `async def load_profile(repo)` → PROFILE. `async def judge(profile, postings)` → `DEMO_JUDGE_DELAY_S` sleep 후 `external_id`별 고정 `Match` 반환, `LLMResult`는 빈 리스트
  - `async def logged_in(provider)` → True
  - `def make_app() -> FastAPI`: `set_fixed_now(FIXED_NOW)`, DB_PATH/RESUME_DIR env 없으면 임시 경로, `Repository` + `JobManager(repo, scrapers=..., profile_loader=..., judge_fn=...)` + `create_app(repo, jobs, logged_in=logged_in, resume_dir=...)`, `FRONTEND_DIST` 있으면 mount (main.py와 같은 방식)
- 테스트 `tests/test_demo.py`
  - `REGISTRY`에 데모 클래스가 없다
  - 데모 스크래퍼 4개가 합쳐 8건, 회사 키가 `REGISTRY`에 존재, display_name이 실제 스크래퍼와 같다
  - judge 결과 등급 분포 strong 2 · good 3 · stretch 3, `level_for(score) == fit_level`, 마감 7일 이내 1건
  - `set_fixed_now` 적용 시 `now_iso()` 고정, `None`으로 해제
  - `make_app()`을 `TestClient`로: 이력서 PUT → provider PUT → interests PUT(4개) → `POST /api/scrape` → 완료 후 `/api/postings` 8건, `/api/companies`의 `last_run.finished_at == FIXED_NOW`, `/api/auth/status.logged_in == true`. 테스트는 `DEMO_JUDGE_DELAY_S=0`, `DB_PATH`·`RESUME_DIR`를 `tmp_path`로 (monkeypatch env)
  - env 없이 `make_app()`해도 `config.DB_PATH`·`config.RESUME_DIR`를 열지 않는다 (임시 경로 사용 확인)

### A2 `feat(backend): --demo entry`
- `app/__main__.py`: `--demo` 플래그. 켜지면 `uvicorn.run("app.demo:app", ...)`로 분기. `app/demo.py` 끝에 `app = make_app()`을 두되, import 부작용이 테스트에 번지지 않게 `if os.environ.get("JOB_POSTING_DEMO") == "1"` 아래에서만 생성하고 `__main__`이 그 env를 세운다 (uvicorn 문자열 import는 같은 프로세스라 env가 전달됨)

## 레인 B: 녹화 (`frontend/`, `src/` 제외)
### B1 `test(e2e): demo recording project`
- `playwright.config.ts`
  - `projects`: `chromium` (`testIgnore: "**/demo.spec.ts"`, 기존 설정 그대로), `demo` (`testMatch: "**/demo.spec.ts"`, `viewport {1000, 720}`, `deviceScaleFactor: 1`, `timezoneId: "Asia/Seoul"`, `locale: "ko-KR"`, `video: {mode: "on", size: {1000, 720}}`, `headless: true`)
  - `webServer.command`는 그대로 `sh e2e/server.sh`. `E2E_DEMO=1`이면 server.sh가 `python -m app --demo`로 띄운다
- `e2e/server.sh`: `E2E_DEMO` 분기 추가. 나머지(임시 경로, fake-bin PATH) 동일
- `package.json`: `"test:e2e": "playwright test --project chromium"`, `"demo:record": "playwright test --project demo"`
- `e2e/demo.spec.ts` (`test.describe.configure({ retries: 0 })`)
  - `resetState()` 후 `page.goto("/")`
  - 단계 사이 `page.waitForTimeout(900)`로 읽을 시간을 준다. 총 길이 30초 이내 유지
  - 업로드: `uploadResume(page)` (helpers의 홍길동 합성 이력서) → 성공 toast 사라질 때까지 대기
  - AI 선택: `radio "Claude Code"` 클릭 → 카드 안 `로그인됨` 텍스트 대기 → `계속`
  - 관심회사: `토스`·`당근`·`카카오`·`네이버` 체크박스 체크 → `확인` → `tablist` 대기
  - `스크래핑 하기` 클릭 → 진행 상태가 보이게 대기 → 공고 카드(`article`) 8장 대기 → 마지막 프레임 2초 유지
  - `afterEach`: `page.video().path()`를 `process.env.DEMO_VIDEO_OUT`(기본 `${E2E_TMP}/demo.webm`)로 복사. 테스트 실패 시에도 복사해 디버깅에 쓴다
- `e2e/make-gif.sh <in.webm> <out.gif>`
  - ffmpeg 2-pass: `fps=10,scale=1000:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer:bayer_scale=3`
  - 끝나면 파일 크기(바이트·MB)와 길이를 출력. 5MB 초과면 exit 1 + "fps 또는 max_colors를 낮춰라" 안내
- 레인 B 검증: `npx playwright test --list`에서 demo spec이 `demo` 프로젝트에만 나오고 `--project chromium`에는 없음. `sh -n e2e/make-gif.sh`
- `e2e/README.md`: demo 프로젝트·`demo:record`·`make-gif.sh` 한 단락
