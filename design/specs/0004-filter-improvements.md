# spec - 회사 filter 개선
## 목표
- 화면 상단의 회사 필터를 select에서 Multi-select로 변경한다

## 목표가 아닌 것
- 백엔드/API 변경 (필터링은 기존처럼 프론트에서 수행)
- 등급 필터 변경
- 북마크/숨김 탭에 필터 추가

## 기능
- 회사 필터는 기본적으로 전체 회사가 선택되어 있다
- 특정 회사를 filter에서 끌 수 있다. (unselect)

## 검증 방법
- 최초 진입 시 모든 회사가 선택되어 있고 전체 공고가 보인다
- select된 회사만 리스팅에 보여진다
- unselect된 회사는 리스팅에 보이지 않는다
- unselect했던 회사를 다시 select하면 해당 회사 공고가 리스팅에 복귀한다
- 전체 끄기를 누르면 모든 회사가 해제되고 empty view가 보인다. 전체 켜기를 누르면 모든 회사가 선택되고 전체 공고가 보인다
- 회사 필터와 등급 필터는 AND로 적용되고, 상단 건수(`N건`)에도 반영된다
- 드롭다운의 회사별 공고 수는 현재 등급 필터를 반영하고 숨긴 공고를 제외한 값이다. 등급 필터를 바꾸면 함께 바뀐다
- 회사 필터를 바꾸면 무한 스크롤이 처음 20건부터 다시 시작한다
- 필터 선택 후 다른 탭에 갔다 돌아오거나 새로고침해도 선택이 유지된다
- 브라우저 탭을 닫고 새로 열면 기본값(전체 선택)으로 돌아간다
- 세션 중 새로 추가된 회사는 선택된 상태로 나타난다
- sessionStorage 접근이 실패하거나 저장값이 깨져 있어도 기본값으로 정상 동작한다

## 결정 사항 (2026-10-15)
- UI: 체크박스 드롭다운
  - 닫힌 상태 버튼 라벨은 선택 상태 요약: 전체 선택 시 `전체 회사`, 일부 선택 시 `토스 외 2곳`, 전부 해제 시 `선택 없음`
  - 바깥 클릭 또는 Esc로 닫힌다
- 드롭다운 상단에 전체 켜기/끄기 버튼을 둔다. 전체 선택 상태면 `전체 끄기`, 아니면 `전체 켜기`
- 회사를 전부 끄면 empty view를 보여준다 (`선택된 회사가 없습니다`). 전체로 되돌리지 않는다
- 체크박스 항목마다 회사별 공고 수를 표시한다
  - 등급 필터 반영, 숨긴 공고 제외 (= 해당 회사를 켰을 때 리스팅에 추가될 건수)
  - 0건인 회사도 목록에 표시하되 흐리게 처리한다
- 적용 범위는 공고 탭만
- 필터 선택은 DB에 저장하지 않고 브라우저 sessionStorage에 저장한다. 유지 기간은 세션
  - 대상: 회사 필터와 등급 필터
  - 회사 필터는 "해제한 회사 목록"을 저장한다. 새로 추가된 회사가 기본 선택 상태가 되도록
  - 저장소 접근 실패·파싱 실패 시 기본값 사용
