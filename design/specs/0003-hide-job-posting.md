# Spec - 포스팅 비활성화 기능
## 목표
- 포스팅을 브라우징하다가 숨김 처리하고 싶은 포스팅은 숨길 수 있다

## 목표가 아닌 것
- 숨김 기능과 삭제 기능의 통합

## 기능
- 포스팅의 우측에 휴지통 또는 눈깔 아이콘이 있고 이를 누르면 숨김 처리가 된다.
- 숨긴 포스팅만 모아 보는 탭이 따로 있고, 거기서 숨김 처리한 포스팅을 확인하고 숨김을 해제할 수 있다 (토글 버튼)

## 검증 방법
- 숨김 버튼을 누르면 리스트에서 바로 사라지고 숨김 탭에 이동해 보여지는지 확인하기
- 숨김 탭에서 숨김이 활성화된 상태의 버튼을 누르면 다시 job posting 리스트로 복귀하고 숨김 탭에서 사라지는지 확인하기
## 결정 사항 (2026-10-15)
- 숨김 아이콘은 눈(eye-off) 아이콘을 쓴다. 삭제로 오해되지 않도록 휴지통은 쓰지 않는다
- 숨긴 공고는 공고 탭과 북마크 탭 모두에서 보이지 않는다. 숨김을 해제하면 원래 탭에 다시 나타난다 (북마크 상태는 유지)
- 숨김 탭은 공고/북마크 탭과 같은 순서(score 내림차순)로 정렬한다
- 공고가 soft delete되면 숨김 탭에서도 사라지고, 공고가 다시 수집되면 숨김 상태도 복구된다
  - 구현: `hides.deleted_at`은 사용자 해제에만 사용. 공고 삭제 여부는 `postings.deleted_at`과 JOIN으로 판단
- API: `PUT`/`DELETE /api/postings/{id}/hide`, `/api/postings` 응답에 `hidden` 포함
