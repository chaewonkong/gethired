# spec - 북마크 기능

## 문제제기
- job posting 갯수가 수백개 이므로 사람이 모든걸 매번 확인하기 어렵다
- 기존에 봤던 공고를 찾기도 어렵다

## 목표
- 공고를 북마크할 수 있다
- 북마크한 공고만 확인하는 탭이 새로 추가된다

## 기능
- 리스팅 확인 중 별표를 누르면 북마크가 된다
- 북마크도 DB에 저장하며, 공고가 delete되면 북마크도 soft delete되어야 한다
- 공고, 회사 외에 북마크라는 세번째 탭이 추가된다
- 북마크를 하는 별표는 누르면 별이 노란색으로 채워지면서 저장되고 한번 더 누르면 별이 비면서 해제된다
- 북마크 탭에서도 북마크를 해제할 수 있다.

## 구현 및 검증방법
- 리스팅 중에서 특정 공고의 별을 누르면 북마크가 되고, db에 데이터가 삽입된다.
- 리스팅 중에 북마크된 공고의 별을 누르면 db에서 데이터가 soft-delete된다
## 결정 사항 (2026-10-09)
- 공고가 soft delete되면 북마크도 북마크 탭에서 사라지고, 공고가 다시 수집되면 북마크도 복구된다
  - 구현: `bookmarks.deleted_at`은 사용자 해제에만 사용. 공고 삭제 여부는 `postings.deleted_at`과 JOIN으로 판단
- 마감/삭제된 공고는 북마크 탭에 표시하지 않는다
- 북마크 탭은 score 내림차순. 필터 없음
- 북마크 탭에서 별을 해제하면 즉시 목록에서 빠진다
- API: `PUT`/`DELETE /api/postings/{id}/bookmark`, `/api/postings` 응답에 `bookmarked` 포함
- `just reset-db`는 DB 파일을 지우므로 북마크도 함께 삭제된다
